# Plant photos for the screenshots

The README's screenshots (`make screenshots`) show these plants, in a demo household made by
`python manage.py demo_household`:

| File | Plant |
|---|---|
| `aloe-vera.webp` | Aloe vera |
| `avocado-seedling.webp` | Avocado (*Persea americana*) seedling, rooting in water |
| `dracaena.webp` | Dragon tree (*Dracaena marginata*) |
| `flaming-katy.webp` | Flaming Katy (*Kalanchoe blossfeldiana*) |
| `golden-pothos.webp` | Golden pothos (*Epipremnum aureum*) |

Photos by the maintainer of Sunfleck, licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), like the care dataset. They
were resized to 1280 px and saved without any metadata.
